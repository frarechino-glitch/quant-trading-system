# Quant Trading System

Sistema experimental de trading cuantitativo.

## Objetivo

Desarrollar, validar y probar estrategias de trading mediante:

- análisis cuantitativo
- backtesting
- pruebas fuera de muestra
- paper trading
- generación de señales
- posterior automatización

## Estado

Fase 0 — Arquitectura inicial.

## Regla principal

No se utilizará dinero real hasta demostrar una ventaja estadística robusta mediante pruebas históricas y fuera de muestra.
